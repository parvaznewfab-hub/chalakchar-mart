# ChalakChar Mart

A modern Flutter-based multi-vendor eCommerce marketplace built with Firebase.

## 📱 Overview

ChalakChar Mart is a scalable marketplace application where customers, vendors, delivery partners, and administrators can manage the complete shopping experience through a single platform.

The application is built using Flutter and Firebase with a clean, maintainable, and scalable architecture.
